# 《雷牌》实现进度

实现顺序以根目录 `策划案.txt` 第 17 节为准。规则层位于
`Assets/GameScripts/HotFix/GameLogic/LeiPai/`，不依赖 UI 动画。

卡牌内容由 Luban 的 `leipai.TbCard` 统一维护。运行态只保存 `CardId`，
通过 `LeiPaiLubanCardCatalog.Load()` 读取卡牌名称、线索身份和通用效果；
不存在按具体卡牌种类扩展的运行时枚举。

## 当前验证

- 同一随机种子生成完全一致的布局与入口。
- 默认棋盘严格包含 25 基础卡、6 地雷、3 核心和 2 工具卡。
- 共鸣器周围至少存在两张基础卡。
- 所有八邻域线索与实际地雷、核心数量一致。
- 入口不计分、不累计基础卡、不消耗翻牌次数。
- 工具卡返还翻牌次数；踩雷扣盾且分数不低于零。
- 侦察不翻牌、不触发、不消耗翻牌次数；无效目标不扣次数。
- 六种核心按激活顺序执行；共鸣只做固定贡献，不递归触发其他核心。
- 即时收益先汇总再应用倍频器；收集器蓄能独立保存并在达标时兑现。
- 三关目标、资源和奖励池由 `leipai.TbLevel` 配置；远征保留核心池并支持同种子重试。
- 1920×1080 的 UGUI 原型已烘焙为 JSON v2，共 88 个节点、36 个卡牌按钮。
- HTML/JSON 原型保存在 `Assets/Editor/LeiPai/Html/`，不会进入 YooAsset 运行时资源收集。
- 主界面已接入左键翻牌、右键循环标记、侦察/拆分线索、同种子重试、三选一奖励与 HUD 刷新。
- 翻牌表现与规则计算分离；结算贡献按规则输出顺序逐项播放，期间锁定输入并支持窗口销毁取消。
- 教学局使用独立固定种子，按“翻牌 → 标记 → 侦察/拆线索 → 翻核心”逐步解锁操作；可随时跳过，完成后会新建随机三关远征，不把教学进度带入正式计分。
- 八种短音效通过 `GameModule.Audio` 和 YooAsset 地址播放，覆盖翻牌、标记、侦察、基础得分、核心触发、倍率、踩雷以及过关/胜利反馈；顺序结算会按贡献来源选择声音。
- 线索数字独立使用红/绿/黄/灰表达邻域组成，并在卡牌左上角、右下角重复显示；卡牌类型、玩家标记、侦察和安全确认改用独立状态边框。
- 侧栏公开未翻牌的基础、地雷、核心和工具数量，但不暴露具体位置。
- 棋盘提示区持续显示翻牌/侦察模式；悬停已翻开或已侦察卡牌时显示配置表中的规则说明，悬停玩家标记时明确提示它不是系统确认。
- 顺序结算会定位实际贡献来源：基础收益高亮当前翻牌，核心收益高亮对应核心，倍率收益高亮倍频器，并使用不同强调色和音效。
- 规则层的每项分数贡献携带稳定的语义类型与来源坐标；UI 不再解析中文来源文字。音效、音量和强调色统一由 `LeiPaiPresentationProfile` 映射，新增核心卡无需修改窗口判断。
- 单卡渲染已抽为 `LeiPaiCardView`，统一负责中央文本、双角线索、背景、状态边框与可交互状态；`LeiPaiMainUI` 只协调规则、教学和表现队列。
- 教学步骤、操作门禁、提示文案和主按钮状态已抽为无 Unity 依赖的 `LeiPaiTutorialFlow`；卡牌核心/地雷等稳定语义统一由配置字段推导，不枚举具体卡牌品种。
- 棋盘已改用项目现有的 `SuperScrollView.LoopGridView`：主界面不再保存 36 个静态按钮，只引用一个 `LeiPaiCardItem` Prefab，由列表对象池根据棋盘数据生成和回收。

编辑器测试位于 `Assets/GameScripts/Tests/Editor/LeiPai/`。
